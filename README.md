# Singapore, together · 一起遊獅城

Four days in Singapore, 13–16 November 2026. Static HTML, CSS and JavaScript; all photographs are included. Open index.html in a browser to preview locally.

## Publish on GitHub Pages

1. Unzip the download. Upload the **contents** to the root of your GitHub repository. Keep index.html at the root and keep the img folder intact.
2. In the repository, open Settings → Pages. Under Build and deployment choose **Deploy from a branch**.
3. Choose your branch (usually main), choose **/(root)** and save. GitHub displays the published address after the Pages deployment completes.
4. For a Traditional Chinese link, append ?lang=zh to that address. Append ?lang=en for English. For a particular day, add &day=fri, &day=sat, &day=sun or &day=mon.

## Adjust the itinerary

Edit the stop times, text pairs, photo names and map destinations in itinerary.js. Each text pair lists English first and Traditional Chinese second. Food and sightseeing links use Google Maps place searches. Official visitor links and interface labels live in app.js. Change colours, typography and layout in style.css.

On Friday the two map buttons are intentional. When you know the Cheng Ji branch, remove the other button and update the timing note in both languages. The return airline and departure terminal are also unconfirmed.

Commit the edits to the configured Pages branch to update the website. Photo attribution and license links are in credits.html.
